## Исследование альфа-стратегий на данных NASDAQ (2016–2022)

Репозиторий посвящен разработке и анализу альфа-стратегий на основе исторических данных OHLCV (котировки акций NASDAQ) за шестилетний период (2016 - 2022)

### Структура проекта

#### /alphapackage — Библиотека инструментов
Модуль для работы со стратегиями:
* **Базовый класс альф**: класс BaseAlpha, от которой наследуются все конкретные стратегии, содержащий методы для расчета финансовых метрик
* **Инструментарий формул**: функционал для преобразований формул альф
* **Обработка данных**: класс DataHolder для загрузки, очистки и подготовки данных OHLCV к анализу

#### /labs — Исследовательские ноутбуки
Серия ipynb-ноутбуков, в которых импортируются инструменты из `alphapackage` для проведения тестов:
* Расчет доходности и коэффициента Шарпа
* Анализ остальных финансовых метрик на временных промежутках
* Оценка корреляции между различными альфами
